# ZOSIMAS Digital Solution PLC

Premium React website for **ZOSIMAS Digital Solution PLC**.

**WEB • MOBILE • AI**  
**Innovate. Build. Transform.**

## Stack

- React
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router
- Framer Motion
- Lucide React

## Develop

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## Placeholders

Until official information is supplied, the site uses:

- `[Company Email]`
- `[Phone Number]`
- `[Company Address]`
- `[LinkedIn URL]`

The contact form updates Redux state (`idle` → `submitting` → `success` / `error`) and is ready for a future API. It does not send email.

Projects are representative work types, not named clients, testimonials, or claimed results. Careers listings are placeholders.
